## 使用条件

1. **[TC-3]** 「アンカーを増やすとv1(3.27%)に収束する」と書かない。正: 「収束せず、単一マスク選択でD180が4.0〜6.7%に振れる境界依存レジームを選ぶ=識別されない(レジーム多重性の露呈)」
2. **[TC-4]** 限界価値の結論は「テール識別は未達成、追加アンカーの限界情報価値はほぼ無〜負、stage1〜3の見かけの安定はコーナー収束(全再スタートが同一境界に落ちる)による偽物」に限定
3. **[TC-2/c]** D180は**6.72%と4.53%を必ず併記**し、いずれも確定推定として単独引用しない。前者=凍結規約(10月マスク)の結果だが**既知の時点誤りに汚染**(25-10チャートは終端2025-11-09を明示ラベルしており、アンカー値418,242はNov-09の値。10月マスクは規約選択ではなく実証的な時点誤り——誤り訂正はHARKingではない、が凍結値の透明報告も維持)。後者=誤り訂正後のより物理的に妥当な値。**頑健な結論は「識別されない」であり、どちらの値でもない**
4. **[TC-1/d]** stage4〜5の構造分解値(λ/k/p/c/τ)を信頼しない。kは緩めた分だけ上限に張り付くrunawayパラメータで、**D1=0.77〜0.80を物理的保持として引用禁止**(Novマスクではk=0.29〜0.54・D1=0.34〜0.41の物理域に戻る=10月マスク誤設定に固有の症状)
5. **[TC-5]** D180 CI幅は**定性利用のみ**(「単調に縮小しない」まで)。n_boot=100・stage5別シード(20265725、外部kill復旧時)のため幅の微差(例: 1.04 vs 1.19)を定量比較しない
6. **[未実行の任意項目]** 「11月マスク×境界緩和」の組は未実行。stage5残存短τ(τ=200@Novマスク)が真の残存かさらなる境界産物かは**未切り分け**——「断定不可」以上に踏み込まない
7. **[除外]** コラボ発表時期・非対称性に関する未検証の観察はタスクcの解釈に使用しない
