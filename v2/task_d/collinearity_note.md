# stock/base共線性の数理化ノート(v2 Phase 4後半)

**状態: 監査承認済み(数式検算で誤りゼロ、2026-07-20)+監査推奨の記述修正5点を反映済み。**
素材となる定義式は監査済み(`reconciliation_report.md` §4、実装一致確認済み 2026-07-20)。

## 0. 目的

v1タスクc(多タイトル適用)で観測された「stock=0またはbase=0への縮退」が、フィッティングの不具合ではなく**CCUのみの観測に内在する識別不能性**であることを、閉形式で示す。

## 1. 監査済みの定義(実装からの抽出)

- 保持カーネル: R(d) = R_fast(d) + p·c·e^{−d/τ}(R_fastは短期成分、時定数はτより十分小)
- base列: x_base(t) = Σ_{i=0}^{t} R(i)(`core.py build_X` 列0、係数 a₀ = 定常流入 人/日)
- stock列: x_stock(t) = e^{−t/τ}(`task_c.py _design` 最終列、`use_stock=True` のタイトルのみ。係数 a_s = t=0 既存人口。**τはRの長期成分と共有**)
- 両係数は素のNNLS(非負制約、正則化なし)で単一目的関数に入る。適合はburn-in除外後の窓 W = [t₀, T](t₀=90)で評価
- use_stock=True: WarThunder/FF14/RimWorld/Warframe/DbD/PoE(PoE2はFalse)

## 2. 基本恒等式: base列はstock列のアフィン変換に漸近する

長期成分の離散和は等比級数で閉じる:

  Σ_{i=0}^{t} p·c·e^{−i/τ} = G·(1 − e^{−(t+1)/τ}),  G ≡ p·c/(1 − e^{−1/τ}) ≈ p·c·τ (τ≫1)

短期成分の累積 F(t) = Σ_{i=0}^{t} R_fast(i) は t が短期時定数の数倍を超えると定数 F_∞ に飽和する。よって burn-in後(t ≥ t₀ = 90 ≫ 短期時定数)の窓上で:

  **x_base(t) = K − G′·x_stock(t) + O(ε)**,  K ≡ F_∞ + G,  G′ ≡ G·e^{−1/τ},  ε = |F(t)−F_∞|

つまり窓W上で {x_base, x_stock} が張る空間は **{1(定数), e^{−t/τ}}** が張る空間と一致する。係数の対応は

  a₀·x_base + a_s·x_stock = a₀K·**1** + (a_s − a₀G′)·**e^{−t/τ}**

であり、写像 (a₀, a_s) → (a₀K, a_s − a₀G′) は三角形で常に可逆。**したがって識別不能性は「1 と e^{−t/τ} が窓上で区別できるか」に完全に帰着する**。

## 3. 二つの崩壊モード

窓W上の u(t) = e^{−t/τ} について:

**(i) τが窓長に比べ大きい(τ ≫ T−t₀)**: u(t) ≈ e^{−t₀/τ}·(1 − (t−t₀)/τ)。定数からの相対変動は

  CV(u) ≈ (T−t₀)/(τ·√12)

**例示**として T−t₀ = 1222−90 = 1132日(Limbusの窓。ただしLimbus自身はuse_stock対象外でstock列を持たない——数値はスケール感の例示であり、Limbusのstock縮退の主張ではない)を取り、τ=6000日(v1・v2タスクcで観測された上限張り付きレジーム)とすると CV ≈ 1132/(6000·3.46) ≈ **5.4%**——uはほぼ定数となり、{1, u}は数値的にランク落ちする。このとき識別されるのは組合せ a₀K + (a_s − a₀G′)·ū の1自由度のみで、a₀とa_sは分離できない。実際のstockタイトル(WarThunder等)は観測窓がより長く、同じτならCVはこれより大きい(=識別しやすい)ため、この例示は保守寄りである。

なお、実装のNNLSは重み付き設計(rows = X·(mult/y)、yは経時増加するCCU)上で解かれるため、共線性・CVは厳密には**重み付き列空間**で評価すべきである(`scripts/stock_collinearity.py` がraw/weighted両方の指標を算出済み)。本節の非重みCVはその近似である。

**(ii) τがburn-inに比べ小さい(τ ≲ t₀/ln(1/δ))**: 窓上で u(t) ≤ e^{−t₀/τ} ≈ 0(例: τ=30日なら e^{−3} ≈ 0.05、τ=20日なら 0.011)。stock列そのものが数値的に零列となり、a_sは目的関数に寄与しない=識別不能(NNLSは自明に a_s の任意値を許し、実装上は0に落ちる)。

**識別可能なτの帯**はこの二つに挟まれた中間域(オーダーとして t₀ ≲ τ ≲ (T−t₀)/数倍)に限られる。

## 4. NNLSの非負制約がコーナー解を強制する

モード(i)の準ランク落ち下では、目的関数はa₀–a_s平面の縮退方向(a₀K + (a_s−a₀G′)ū = 一定の稜線)に沿ってほぼ平坦になる。非負制約 a₀, a_s ≥ 0 の下でノイズがこの稜線をわずかに傾けると、最適解は稜線と制約境界の交点=**コーナー(a_s=0 または a₀=0)に落ちる**。どちらのコーナーに落ちるかは残差とu方向の微小な相関の符号で決まり、**実質的にノイズのコイントスである**。

これがv1タスクcで観測された縮退(タイトルによりstock=0/base=0が混在)の機構であり、「縮退した側の係数が実際に零である」ことを意味しない。同じ理由で、**縮退の再現安定性(再スタートで毎回同じコーナーに落ちること)は識別の証拠にならない**(稜線の傾き符号が同一データ内では固定されるため)——v2タスクcのstage1〜3「コーナー収束による偽の安定」と同型。

## 5. 含意

1. **アンカーなしタイトルの構造パラメータ全滅(v1)の理論的裏付け**: use_stockタイトルでτが境界に走る挙動とstock/base縮退は独立の不具合ではなく、**同根の**識別不能性の症状である(厳密には前者はτ形状の識別、後者は固定τ下での振幅分割という別の自由度だが、§3(i)の同じ縮退幾何に由来する)
2. **左打ち切り補正(stock)がCCUのみから識別できるのは中間τ帯のみ**であり、その帯の外では外部情報(アンカー等)なしに補正量を推定できない——「開示1点の限界価値」というv2の問いに接続する。ただしこれは**必要条件の主張**であり、「アンカーがあれば識別できる」という十分条件ではない(現にv2タスクcはアンカー5点でもD180テールを識別できなかった)
3. burn-in長 t₀ と観測長 T の設計が識別帯の幅を直接決める(t₀を延ばせば(ii)が悪化、Tを延ばせば(i)が緩和)

## 6. 限界

- **F飽和仮定は当のstockタイトルで破れうる(重要)**: §2の「t₀ ≫ 短期時定数」はLimbus級のパラメータ(λ≈1.4)では成立するが、実際のstockタイトルはλが上限30に張り付く(WarThunder/FF14/RimWorld既知)。λ=30, k=0.3ではR_fast(90)≈0.25で**t₀=90時点で未飽和**であり、O(ε)は小さくない——2列アフィン還元は当該タイトルでは近似が粗くなる。本ノートの結論は「縮退の機構の閉形式的説明」として読み、タイトル別の定量主張には`stock_collinearity.py`の実測指標を使うこと
- R_fastとの分離(短期時定数がτに近い場合)は本ノートの範囲外
- **イベント列との相互作用は縮退を過小評価しうる**: 各イベント列もRとの畳み込みでτ裾を持つため、定数・緩減衰方向はbase/stock/イベント列裾が共有し、実際の準零空間は2次元を超えうる。§4のクリーンな2次元コーナー像は**退化の下限**であり、実際の縮退はより高次元でありうる
- NNLSの重み付き幾何(§3末尾の注記)——非重みCVは近似
- CV(u)の閾値(何%以下で実用上ランク落ちか)はノイズ水準に依存し、ここでは規範値を与えない
